# Mosaic Builder
Mosaic Builder allows you to copy features from other layers and quickly recreate a single merged outline. It also allows you to keep the selected features as individual polygons. This allows you to mosaic together features from different source layers into a single dataset, with a quick and simple UI designed for non-GIS professionals.

# Installing
You can install the latest stable version from the QGIS Plugins repository by going to Plugins - Manage and Install Plugins and searching for Mosaic Builder. 

[Mosaic Builder on QGIS Plugins website](https://plugins.qgis.org/plugins/mosaic_builder/)
